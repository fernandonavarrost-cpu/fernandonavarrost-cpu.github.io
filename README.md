## Como executar

O projeto é estático e não possui dependências nem build. Basta abrir o `index.html` no navegador:

```bash
# Linux / macOS
xdg-open index.html

# Windows
start index.html
```

Ou, se preferir, suba um servidor local:

```bash
python -m http.server 8000
# acesse http://localhost:8000
```
